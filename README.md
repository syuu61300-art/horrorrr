# 闇の一軒家 ― 脱出

ブラウザで遊べる一人称3Dホラー脱出ゲーム（Three.js）。

## 遊び方
懐中電灯と電池を探し、家中（11部屋）に隠された6つの鍵を集めて、幽霊から逃げながら玄関から脱出します。幽霊の移動はプレイヤーの歩きより遅いので、落ち着いて距離を取りましょう。

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 視点 | マウス |
| ダッシュ | Shift を押しながら移動 |
| しゃがみ | C（押している間） |
| スライディング | 移動中に Shift + C |
| 調べる・開ける | F（玄関の扉の前で） |
| ライト | E（懐中電灯を拾うと使用可） |
| メニュー・設定 | Esc |

設定（感度・FOV・モーションブラー・明るさ・音量・描画解像度・FPS上限・FPS表示）はタイトル画面、または Esc のメニューから変更できます。

## ファイル構成
- `index.html` … ページ本体
- `style.css` … UIのスタイル
- `game.js` … ゲーム本体

## 公開方法（GitHub Pages）
1. 4ファイルをリポジトリ直下にアップロード
2. Settings → Pages → Branch を `main` / `(root)` に設定
3. 表示された URL を開く

## 使用ライブラリ
[Three.js](https://threejs.org/) r128（MIT License）を cdnjs から読み込んでいます。

## 横画面
縦持ちのときは自動で画面を90度回転して横画面表示にします（設定「縦持ち時は横表示」でオフ可）。端末を横向きにすると通常表示になります。

## 敵AI
幽霊は歩きより遅く（追跡1.2m/s・巡回0.55m/s）、壁・ドア枠・家具を貫通しません。視界の正面でしか気づかず、暗い場所・しゃがみ・背後では見つかりにくく、見失うと最後に見た場所へ向かってから諦めます。

## スマホ操作
左スティック＝移動 ／ 右側ドラッグ＝視点 ／ ボタン＝調べる・ライト・しゃがむ（切替）・スライド・ダッシュ（切替）／ 右上☰＝メニュー・設定。
スマホを自動判定します（設定の「タッチ操作」で手動切替も可）。横画面推奨。
